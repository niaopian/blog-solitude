RHCE 9 学习笔记：核心系统管理

本文是基于 RHCE 9 学习过程中的一份详细笔记，旨在系统性地梳理 Linux 在文件、用户及权限管理方面的核心知识点。内容涵盖了从基础命令到高级权限设置的各个方面，适合初学者入门及有经验者复习。

linux一级目录

1.根目录是Linux目录结构的最顶级目录。

2.boot目录存放系统的启动配置文件和内核文件。

3.dev目录存放Linux的设备文件。

4.etc目录存放Linux的配置文件。

5.home目录存放普通用户的家目录。

6.mnt目录作为挂载点目录。

7.run目录作为挂载点目录。

8.opt目录存放软件文件。

9.proc目录存放进程文件。

10.srv目录存放资源文件。

11.tmp目录存放临时文件。

12.usr目录是软件默认安装的目录。

13.var目录存放日志文件。

一、文件和目录管理

文件管理是操作系统的基础。本章将介绍如何在 Linux 环境中高效地进行文件的查看、创建、编辑、复制和删除等操作。

1.1 查看文件和目录

查看属性 (ls)

ls 命令用于列出目录中的文件和子目录。

  • ls: 直接使用，不带参数，仅打印文件名。

  • ls -l: 显示文件的详细属性，包括权限、所有者、大小和修改时间。

  • ls -lh: 以人类可读的格式（如 KB, MB, GB）显示文件大小。

  • ls -d [目录]: 查看目录本身的属性，而不是其内部的文件。

  • ls -t [目录]: 按照修改时间排序。-rt: 逆序时间排序

跳转文件夹

  • cd -: 返回上个文件夹

查看内容

  • cat [文件路径]: 一次性读取并打印文件的所有内容到屏幕。
  • echo {a..z}: 有规律输出内容，a到z。
  • head [文件路径]: 默认打印文件的前 10 行。
    • -n 5 或 -5: 指定查看前 5 行内容。
  • tail [文件路径]: 默认打印文件的最后 10 行。
    • -f: 持续追踪并显示文件的最新内容，常用于实时监控日志文件。
  • more [文件路径]: 分页显示文件内容，仅支持向后翻页（空格翻页，回车换行），按 q 退出。
  • less [文件路径]: more 的增强版，支持前后翻页，并提供搜索功能。

1.2 创建文件和目录

  • touch [文件路径]: 创建一个或多个空文本文件。如果文件已存在，则更新其修改时间。
  • file [文件路径]: 查看并确定文件的类型。
  • mkdir [目录路径]: 创建一个新目录。
    • -p: 递归创建目录，如果父目录不存在，会一并创建。
    • -v: 显示创建目录的过程，工作中一般不用

1.3 复制、移动和删除

  • cp [源文件] [目标]: 复制文件或目录。
    • 如果目标是一个已存在的目录，文件将被复制到该目录内。
    • 如果目标不存在，则会将源文件复制并重命名为目标。
    • -r: 递归复制，用于复制整个目录。
    • -d: 复制软链接。
    • -a: 归档模式，保留文件原有的所有属性（权限、所有者、时间戳等），通常需要 root 权限才能完整保留所有者信息。
  • mv [源] [目标]: 移动文件或目录，也可用于重命名。
  • rm [文件]: 删除文件。
    • -r: 递归删除，用于删除目录及其内容。
    • -f: 强制删除，不进行任何提示。
    • 对于 root 用户，系统通常会默认设置 rm -i 的别名，以防止误删。
  • rmdir [空目录]: 删除空目录，功能单一，较少使用。

1.4 使用 Vim 进行文本编辑

Vim 是一款功能强大的文本编辑器，拥有多种操作模式。

命令模式 (Command Mode)

这是 Vim 的默认模式，用于执行移动光标、删除、复制等操作。

  • 光标移动: h (左), j (下), k (上), l (右)。
  • 跳转: gg (到文件首行), G (到文件末行), 3G (到第 3 行)。
  • 删除: x (删除光标处字符), X (删除光标前字符), dd (删除当前行), 5dd (删除从当前行开始的 5 行)。
  • 复制: yy (复制当前行), 5yy (复制从当前行开始的 5 行)。
  • 撤销: u (撤销上一步操作)。
  • 进入插入模式:
    • i: 在光标左侧插入。
    • I: 在当前行行首插入。
    • a: 在光标右侧插入。
    • A: 在当前行行尾插入。
    • o: 在当前行下方新建一行并插入。
    • O: 在当前行上方新建一行并插入。

末行模式 (Last Line Mode)

在命令模式下按 : 进入，用于执行保存、退出、替换等命令。

  • :set number: 显示行号。
  • :set nonumber: 关闭行号。
  • :%s/old/new/g: 全局替换，将文件中每一行的所有 “old” 替换为 “new”。
  • :1,$s/old/new/g: 功能同上，明确指定从第 1 行到最后一行进行替换。
  • :%s/old/new/: 将文件中每一行的第一个 “old” 替换为 “new”。

可视化模式 (Visual Mode)

用于选定文本块进行操作。

  • v: 进入字符可视化模式。
  • V: 进入行可视化模式。
  • Ctrl+v: 进入块（矩形）可视化模式。

二、Shell 核心特性

本章介绍 Shell 提供的一些强大功能，如重定向、管道和通配符，它们是编写高效命令和脚本的基础。

2.1 输入输出重定向

重定向允许我们更改命令的默认输入源和输出目的地。

  • >: 标准输出重定向（覆盖）。例如 ls -l > file.txt。
  • >>: 标准输出重定向（追加）。例如 ls -l >> file.txt。
  • 2>: 标准错误输出重定向（覆盖）。
  • 2>>: 标准错误输出重定向（追加）。
  • &> 或 &>>: 将标准输出和标准错误同时重定向。
  • /dev/null: 一个特殊的设备文件，被称为“黑洞”，任何重定向到它的数据都会被丢弃。
  • <: 输入重定向。将文件内容作为命令的输入。
  • <<END: Here Document。允许在命令行中直接提供多行输入，直到遇到终止符（END）。

2.2 管道 (Pipes)

管道符 | 用于将一个命令的输出作为另一个命令的输入。

  • grep: 常用的过滤命令。
    • grep localhost /etc/hosts: 在 /etc/hosts 文件中查找包含 “localhost” 的行。
    • -i: 忽略大小写。
    • -v: 反向查找，显示不包含匹配项的行。
    • -n: 显示匹配行的行号。
    • -A [n]: 显示匹配行及其后的 n 行 (After)。
    • -B [n]: 显示匹配行及其前的 n 行 (Before)。
  • xargs: 将标准输入转换成命令行参数。

2.3 命令别名 (alias)

alias 命令可以为复杂的命令创建简单的别名，以提高效率。

要使别名永久生效，需要将其写入 shell 的配置文件中（如 ~/.bashrc）。

2.4 通配符和正则表达式基础

  • 通配符 (Wildcards) - 用于文件名匹配：
    • ?: 匹配任意单个字符。例如，a?b 会匹配 aab, axb 等。
    • *: 匹配任意数量（包括零个）的任意字符。
    • []: 匹配括号中指定的任意一个字符。例如 a[bcd]b 会匹配 abb, acb, adb。
    • [^]: 匹配不在括号中指定的任意一个字符。例如 a[^1b]c 会匹配 a2c, axc 但不匹配 a1c 或 abc。
    • \: 转义字符，使其后面的特殊字符（如 ?, *）失去其特殊含义。
  • 基础正则表达式 (Regex) - 用于文本内容匹配 (常与 grep 联用):
    • ^: 匹配一行的开头。^# 匹配所有以 # 开头的注释行。
    • $: 匹配一行的结尾。^$ 匹配所有空行。
    • .: 匹配除换行符外的任意单个字符。
    • .*: 匹配任意数量的任意字符（贪婪模式）。
    • ?: 匹配其前面的字符 0 次或 1 次。

2.5 常用快捷键

  • Ctrl + L: 清理屏幕，等同于 clear 命令。
  • Ctrl + A: 将光标移动到行首。
  • Ctrl + E: 将光标移动到行尾。
  • Ctrl + U: 删除从光标到行首的所有内容。
  • Ctrl + K: 删除从光标到行尾的所有内容。
  • Ctrl + W: 删除光标前的一个单词。
  • Ctrl + Y: 粘贴由 Ctrl+U 或 Ctrl+W 删除的内容。
  • Ctrl + S: 锁屏
  • Ctrl + Q: 解锁
  • Ctrl + Z: 将命令后台挂起
  • Esc + .: 引用上一个命令的参数
  • history: 查看历史执行过的命令。

三、用户和组管理

Linux 是一个多用户操作系统，正确的用户和组管理是系统安全的基石。

3.1 用户管理

  • useradd [用户名]: 创建一个新用户。
    • -g [组名]: 指定用户的主组（Primary Group）。
    • -G [组名]**: 指定用户的附加组（Attached Group）。
  • usermod: 修改已存在用户的信息，参数与 useradd 类似。
  • userdel [用户名]: 删除用户。
    • -r: 在删除用户的同时，删除其家目录和邮箱。
  • id [用户名]: 查看用户的 UID、GID 和所属的组信息。

3.2 用户组管理

  • groupadd [组名]: 创建一个新用户组。
  • groupmod: 修改组名等信息。
  • groupdel [组名]: 删除一个用户组。
  • gpasswd: 管理用户组的工具。
    • -a [用户] [组]**: 将用户添加到组中。
    • -d [用户] [组]**: 将用户从组中移除。

3.3 密码管理

用户密码

  • passwd [用户名]: 为用户设置或修改密码。普通用户只能修改自己的密码。
    • -d: 删除用户的密码，使其可以无密码登录。
    • -l: 锁定用户账户，使其无法登录。
    • -u: 解锁用户账户。
    • -e: 强制用户在下次登录时修改密码。
  • chage: 更灵活地管理用户密码的有效期信息。
    • -m: 密码最短有效期（天）。
    • -M: 密码最长有效期（天）。
    • -W: 密码到期前警告天数。
    • -I: 密码过期后宽限天数（大写 i）。
    • -E YYYY-MM-DD: 设置账户的失效日期。

用户组密码

  • gpasswd [组名]: 为用户组设置密码。
  • newgrp [组名]: 临时切换当前会话的主组。如果目标组设置了密码且当前用户不是其成员，则需要输入组密码才能切换。

3.4 相关配置文件

  • /etc/passwd: 存储用户信息（用户名、UID、GID、家目录、Shell等），密码已被 x 替代。
  • /etc/shadow: 存储用户的加密密码和密码策略信息。
  • /etc/group: 存储用户组信息（组名、GID、组成员）。
  • /etc/gshadow: 存储用户组的加密密码信息。

四、权限管理

权限决定了“谁”能以“何种方式”访问“哪个文件或目录”。

4.1 Linux 标准权限 (rwx)

使用 ls -l 查看时，权限位由 10 个字符组成，例如 -rwxr-xr--。

  • 权限主体: 分为三组：所有者 (u)、所属组 (g)、其他人 (o)。
  • 权限含义:
    • 对于文件:
      • r (读): 可以读取文件内容。
      • w (写): 可以修改文件内容。
      • x (执行): 可以作为命令执行。
    • 对于目录:
      • r (读): 可以列出目录中的文件和子目录列表（需配合 x 权限）。
      • w (写): 可以在目录中创建、删除、重命名文件（需配合 x 权限）。
      • x (执行): 可以进入该目录，是访问目录下任何文件或子目录的前提。

修改权限和所有权

  • chmod: 修改文件或目录的权限。
    • 符号模式: chmod u=rwx,g=rx,o=r file。
    • 数字模式: chmod 754 file (r=4, w=2, x=1)。
  • chown: 修改文件或目录的所有者和所属组。
    • chown [用户] [文件/目录]。
    • chown [用户]:[组] [文件/目录]。
  • chgrp: 单独修改文件或目录的所属组。

4.2 默认权限：umask

umask 用于设置新建文件和目录的默认权限。它是一个“掩码”，系统会从最大权限中“减去”umask 值。

  • 文件最大权限: 666 (-rw-rw-rw-)。
  • 目录最大权限: 777 (drwxrwxrwx)。
  • 计算方法: 默认权限 = 最大权限 - umask
  • 查看 umask: 直接输入 umask 命令。

例如，如果 umask 是 0022，则新建文件的默认权限是 666 - 022 = 644 (rw-r–r–)，新建目录的权限是 777 - 022 = 755 (rwxr-xr-x)。

4.3 特殊权限

  • Set UID (SUID):
    • 表现形式: 所有者权限位的 x 变为 s (如 -rwsr-xr-x)。
    • 作用: 当任何用户执行此文件时，该进程会临时拥有文件所有者的权限。这对于需要临时提升权限的命令（如 passwd）至关重要。
    • 设置方法: chmod u+s file 或 chmod 4755 file。
  • Set GID (SGID):
    • 表现形式: 所属组权限位的 x 变为 s (如 -rwxr-sr-x)。
    • 作用（目录）: 在此目录下创建的任何新文件或目录，其所属组都会自动继承该目录的所属组。
    • 作用（文件）: 执行此文件时，进程会临时拥有文件所属组的权限。
    • 设置方法: chmod g+s dir 或 chmod 2755 dir。
  • Sticky Bit (粘滞位):
    • 表现形式: 其他人权限位的 x 变为 t (如 -rwxr-xr-t)。
    • 作用: 通常用于对全体用户可写的目录（如 /tmp）。设置后，目录中的文件只有其所有者和 root 用户才能删除，防止用户误删他人的文件。
    • 设置方法: chmod +t dir 或 chmod 1777 dir。

注意: 如果原先没有 x 权限，特殊权限会显示为大写的 S 或 T。

4.4 访问控制列表 (ACL)

当标准 ugo 权限无法满足复杂的多用户授权需求时，可以使用 ACL。

  • setfacl: 设置 ACL 权限。
    • -m: 修改或添加 ACL 条目。例如 setfacl -m u:username:rwx file。
    • -x: 删除指定的 ACL 条目。
    • -b: 删除所有 ACL 权限，恢复到标准权限。
    • -d: 设置目录的默认 ACL，目录下新建的文件会自动继承此 ACL。例如 setfacl -m d:u:hzz:r test/。
  • getfacl [文件/目录]: 查看 ACL 详细信息。

当一个文件设置了 ACL 后，ls -l 的权限位后面会多一个 + 号。

权限委派

权限委派就是让普通用户能获得管理员权限的一种方式
我们在权限委派部分只会讲/etc/sudoers文件操作，不会将pam模块高级设计。
sudoers文件允许特定的用户在运行某些命令的时候能将权限提升到和root一样，甚至不需要使用root密码。
tgbALL=(ALL)ALL
表示tgb用户能在任何地方运行任何命令
%tgbALL=(ALL)ALL
表示tgb用户组内的用户能在任何地方运行任何命令
tgbALL=/sbin/useradd
表示tgb用户只能运行useradd管理命令
%tgbALL=(ALL)NOPASSWD: ALL
表示tgb用户组内的用户能在任何地方运行任何命令，且不需要输入tgb自己的密码
后面讲到ansible，所有的被管理主机都不能使用root权限操作，都需要使用普通用户提权到root来进行自动化
操作。
